## Overview

Manavoori Muchhatlu App is an Android project. Java screens in the source include Add Post, Admin, Edit Profile, Home, Login, My Posts, Notifications, Post Detail.


What is actually in the repository: `app/`, `gradle/`. GitHub reports the primary language as Java.

## Features


- Add Post
- Admin
- Edit Profile
- Home
- Login
- My Posts
- Notifications
- Post Detail
- Profile
- Referral
- Register
- Settings
